# Ayo Belajar Bareng

Game belajar Matematika dan Sains untuk anak TK. Buka di Chrome Android, lalu pilih **Tambahkan ke layar utama**. Setelah dibuka sekali, aplikasi berjalan tanpa internet.

Tanpa iklan, tanpa akun, tanpa mengirim data ke mana pun. Progres hanya tersimpan di perangkat. Lisensi gambar dan huruf: [LISENSI.md](LISENSI.md).
